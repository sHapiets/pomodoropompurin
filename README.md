### What really is this?

This is an active Git repository and build launcher (via Github Pages) for the PomodoroPomPurin app.

PomodoroPomPurin is a web app developed with the Flutter SDK, in which you will find most of the scripts in Dart. It is a productivity app, which is inspired by the Pomodoro timer concept, a study routine which involves 5-minute break intervals for every 25-minute of focus. 

One of the key elements of this app, as you may have noticed, is that the app is also inspired by Pompompurin, a golden-retriever modeled mascot in the Sanrio universe, well-known for its distinct design and cuddleable appearance. The entire app mostly revolves around this jolly theme, with a mix of a soothing and lighthearted atmosphere.
